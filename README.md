# 商业计划书 / 可研报告脱敏详情图生成工具

这是一个 Windows 本地运行的交付文件保护工具。文件只在本机处理，不调用外部上传接口。

## 当前功能

- 拖拽或手动选择 PDF、DOCX、DOC 文件。
- PDF 会直接处理，不做排版转换；DOCX/DOC 可通过 LibreOffice headless 自动转成 PDF，再走统一处理流程。
- 用 PyMuPDF 识别可复制文字型 PDF 中的敏感文本区域，并读取 `rules_sensitive.json` 中的商业计划书/可研报告规则。
- 从封面和前 5 页提取公司名、项目名、地址、项目代码、金额和财务指标，作为本次任务的临时敏感词库并全文复用。
- 脱敏 PDF 会先把原始 PDF 渲染成图片，完成图片层马赛克后再合成为多页 PDF，不保留原始可复制文字层。
- 分页详情图从原始 PDF 渲染后再用 Pillow 做马赛克、模糊、浅灰马赛克或黑块。
- 生成 JSON 报告，记录类型、页码、坐标、处理方式、是否人工添加。
- 支持在页面预览中手动框选新增遮挡区域，并支持撤销当前页上一处、清空当前页手动遮挡。
- 新增 Excel 客户预览版生成器：上传 `.xlsx` / `.xlsm` 后生成新的预览版 Excel，不设置打开密码，只设置编辑/保护密码。
- Excel 图片化防复制版：默认模式，把工作表按当前显示效果截图并烙印水印，输出仍为 `.xlsx`，不保留原始单元格数据。
- Excel 普通锁定版：保留真实单元格结构，公式转值、添加水印、保护工作表和工作簿结构。
- Excel 水印预览：上传 Excel 后可先选择某个工作表生成水印效果预览图，再生成正式预览版 Excel。

## 依赖环境

- Windows 电脑；
- Python 3.10+，推荐 Python 3.12 x64；
- `requirements.txt` 中的 Python 依赖；
- LibreOffice，用于 DOCX/DOC 自动转 PDF；
- Microsoft Excel 或 WPS 表格自动化支持，用于 Excel 真实截图和公式转值。

## 启动方式

推荐先在项目目录双击：

```text
创建桌面快捷方式.bat
```

它会在当前 Windows 用户桌面创建：

```text
商业计划书脱敏详情图工具.lnk
```

以后直接双击这个桌面图标即可启动工具。

也可以在项目目录直接双击：

- `启动工具_应用窗口.bat`：应用窗口模式，优先用 Edge/Chrome 的 app 窗口打开，看起来更像本地 APP。
- `启动工具.bat`：普通浏览器模式，用默认浏览器标签页打开。

两种方式都会启动本地 Flask 服务，并自动打开：

```text
http://127.0.0.1:5000
```

如果 5000 端口被占用，会自动改用 5001。

## 命令窗口说明

启动后会保留一个命令窗口，这是本地 Flask 服务正在运行的窗口。

请不要关闭此窗口，关闭后网页将无法访问。需要停止工具时，直接关闭这个命令窗口即可。

如果页面打不开，先重新双击桌面图标启动；如果仍打不开，看命令窗口里显示的“当前访问地址”，确认是 5000 还是 5001。

## 手动运行

```powershell
.\run_app.ps1
```

也可以手动运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

## 输出位置

所有结果都放在 `output` 目录下，每次处理会创建一个独立任务文件夹：

- `脱敏后_原文件名.pdf`
- `pages/脱敏后_原文件名_page_001.png`
- `脱敏后_原文件名_分页详情图.zip`
- `脱敏后_原文件名_处理报告.json`

原文件不会被覆盖。

Excel 客户预览版会输出：

- `预览版_原文件名.xlsx`
- `预览版_原文件名_处理报告.json`

## 推荐文件流程

如果原文件是 Word，推荐先在 WPS/Word 中手动导出 PDF，再上传本工具。这样工具会直接处理这个 PDF，不会改变原始页面尺寸、页数、行距、表格和分页。

直接上传 DOCX/DOC 时，工具会调用 LibreOffice 自动转换 PDF。LibreOffice 与 WPS/Word 的中文排版引擎不同，可能导致行距、字体替换、表格高度和分页变化，最终出现页数变多或变少。这个模式只建议用于初步预览，不建议作为最终详情图来源。

页面里可以填写“原文件预计页数（可选）”。如果例如预计 56 页，自动转换后变成 94 页，工具会提示页数异常，并建议改用 WPS/Word 手动导出 PDF 后再处理。

## 脱敏 PDF

脱敏 PDF 适合闲鱼详情图、多页预览截图、朋友圈案例展示。它是由已打码分页图片重新合成的 PDF，只保留图片画面，不保留原 PDF 的可复制文字层。

## Excel 客户预览版

页面顶部切换到“Excel 客户预览版”后，可以上传 `.xlsx` 或 `.xlsm` 文件。`.xls` 请先用 Excel/WPS 另存为 `.xlsx` 后再处理。

当前优先使用 Microsoft Excel COM 自动化处理；如果 Excel 不可用，会尝试 WPS 表格 COM；再不可用时才使用 openpyxl 备用方案。Excel/WPS 自动化会打开复制后的文件，计算工作簿，把公式区域粘贴为数值，尽量保留样式、图表、列宽、行高、筛选、冻结窗格和页面设置。

上传 Excel 后，页面会先读取工作表列表。可以选择某一个工作表，调整水印文字、字体大小、颜色、透明度、旋转角度和平铺间距后，点击“生成水印预览图”查看效果。水印预览图只保存在临时目录里用于页面查看，不会生成 PDF、图片包或长图，也不会修改原 Excel 文件。

预览版 Excel 不设置打开密码，客户可以直接打开浏览。页面里的“编辑/保护密码”只用于工作表保护和工作簿结构保护，默认是 `123456`，可自行修改。

水印文字可在页面自定义，默认是“保密文件”。默认会给可见工作表添加浅灰斜向平铺水印，保护工作表，并保护工作簿结构。工作表保护不是强加密，不能替代正式保密协议或文件级加密。

Excel 客户预览版提供两种预览安全模式：

- 图片化防复制版 Excel：默认推荐。工具会优先用 Excel/WPS COM 按工作表当前显示效果真实截图，并把水印烙印到截图图片里，再插入新的 Excel 工作簿中。最终仍是 `.xlsx` 文件，不设置打开密码，但不保留原始单元格数据和公式，客户不能直接复制出原表格里的数字和文字。图片化模式会跳过公式转数值，因为最终文件只保留截图。它仍无法防止截图、拍照或 OCR 识别。
- 普通锁定版 Excel：保留真实单元格结构，公式转数值，添加水印并保护工作表/工作簿结构。这个模式适合需要客户筛选或查看单元格结构的情况，但不能彻底防复制，客户仍可能复制或绕过保护。

如果只是给客户看样式、结构和大概内容，优先使用“图片化防复制版 Excel”。

## GitHub 安全提醒

GitHub 仓库只保存代码、配置、启动脚本、README、规则文件和说明文档。

不要提交以下内容：

- `uploads/`
- `output/`
- `private_samples/` 里的真实文件
- `.venv/`
- `.doc` / `.docx`
- `.pdf`
- `.xls` / `.xlsx` / `.xlsm`
- `.png` / `.jpg` / `.jpeg`
- `.zip` / `.rar`
- `.json` 处理报告
- `.log` 日志

本项目用于本地处理客户文件，不要把客户资料、测试样本或生成结果上传到 GitHub。

## 当前限制

- 第一版优先支持可复制文字型 PDF/DOCX。扫描件或图片型 PDF 需要后续接入 OCR。
- OCR 接口已预留在 `desensitizer/ocr.py`，默认未启用。
- 人工框选选择马赛克时，分页详情图和脱敏 PDF 都会使用图片层效果；添加遮挡只更新当前页预览，导出 PDF 或 ZIP 时再统一生成最终文件。
- 自动脱敏仍可能漏识别，公开展示前请逐页预览并用手动框选补充遮挡。
