# 新电脑恢复使用说明

## 1. 克隆私有仓库

在新电脑上先登录 GitHub，然后克隆私有仓库：

```powershell
git clone <你的私有仓库地址>
cd 敏详情图生成工具
```

## 2. 安装 Python

安装 Python 3.10 或更高版本，推荐 Python 3.12 x64。

如果希望依赖尽量放在 F 盘，可以把 Python 安装到：

```text
F:\Tools\Python312
```

确认命令可用：

```powershell
python --version
pip --version
```

## 3. 安装项目依赖

在项目目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 4. 安装 LibreOffice

LibreOffice 用于 DOCX/DOC 自动转 PDF。推荐安装 Windows x86-64 版本。

优先路径：

```text
F:\Tools\LibreOffice\program\soffice.exe
```

如果不能安装到 F 盘，也可以使用：

```text
C:\Program Files\LibreOffice\program\soffice.exe
```

## 5. 确认 Excel/WPS 可用

Excel 客户预览版的真实截图和普通锁定版优先使用 Microsoft Excel COM。

如果没有 Microsoft Excel，可尝试 WPS 表格 COM。图片化防复制版如果无法调用 Excel/WPS 真实截图，会退回近似绘制模式，复杂图表、图片和排版可能无法完整保留。

## 6. 启动工具

普通浏览器模式：

```text
启动工具.bat
```

应用窗口模式：

```text
启动工具_应用窗口.bat
```

启动后访问：

```text
http://127.0.0.1:5000
```

如果 5000 端口被占用，启动脚本会尝试使用 5001。

## 7. 创建桌面快捷方式

双击：

```text
创建桌面快捷方式.bat
```

它会在桌面创建：

```text
商业计划书脱敏详情图工具.lnk
```

以后双击桌面图标即可启动。

## 8. 安全提醒

本项目只在本地处理文件，不上传客户文件到云端。

不要把客户文件提交到 GitHub。以下内容必须只保存在本机：

- `private_samples/` 里的真实测试文件；
- `uploads/` 上传缓存；
- `output/` 输出文件；
- Word、PDF、Excel、图片、ZIP/RAR、JSON 报告、日志。

新电脑上的真实测试文件仍然建议放到本地 `private_samples`，不要上传。
